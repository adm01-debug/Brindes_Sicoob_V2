## Notas por métrica

### 1. Deals criados
Campo `deals.created_at`, sem filtro de status. **0 no período** — todos os 3 deals do banco são anteriores a 2026-07-18.

### 2. Deals ganhos
Critério: `deals.status = 'ganho'` (valores distintos encontrados no banco: `ganho`, `aberto`). **0 no período.**

### 3. Taxa de conversão
Fórmula: `ganhos / criados × 100`. **Não calculável** — zero criados.

### 4. Ticket médio
`AVG(deals.valor) WHERE status = 'ganho'`. Coluna `valor` existe (tipo numeric). **Não calculável** — zero ganhos no período.

### 5. Ciclo médio de venda
`AVG(EXTRACT(EPOCH FROM (closed_at - created_at)) / 86400)`. Coluna `closed_at` existe. **Não calculável** — zero ganhos no período.

### 6. Proposals geradas
Tabela `proposals` com coluna `created_at`. **0 no período** — única proposal existente é de 2026-04-12 com status `rascunho`.

### 7. Taxa proposal → deal ganho
Via `proposals.deal_id` → `deals.id`. **Não calculável** — zero proposals no período.

### 8. Tempo médio de primeira resposta WPP
**Não mensurável hoje — motivo:** `whatsapp_messages` tem 0 registros; `seller_daily_metrics` tem 0 registros. A coluna `avg_response_time_minutes` existe em `seller_daily_metrics`, mas sem dados. Requisito: popular `seller_daily_metrics` via job diário ou acessar `whatsapp_messages` com dados reais da instância WPP (wpp2).
